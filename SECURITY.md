# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 2.1.0   | :white_check_mark: |
| others  | :x:                |

## Reporting a Vulnerability

Open an issue, and it will be triaged eventually, typically within a month.  (This is a hobby, not a job.)

If desired, describe effect of the vulnerability, while leaving sensitive details out of the initial report; If doing so, it is recommended to provide a way for the maintainers to initiate further contact.
